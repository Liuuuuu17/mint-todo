# Orb Todo

一个参考录屏制作的 macOS 桌面悬浮待办应用。支持 Apple Silicon 和 Intel Mac，要求 macOS 13 或更新版本。

## 安装与使用

1. 解压 `OrbTodo-macOS.zip`，将 **Orb Todo.app** 拖到“应用程序”文件夹，双击打开。
2. 在窗口底部选分组，输入待办，按回车或点 `+` 添加。
3. 点任务本身可以编辑内容、分组和截止时间。设置截止时间后，日期会显示在任务下方。
4. 点方框标记完成；点任务右侧的 `···` 可以改为“进行中”、完成、取消或删除。主界面仅显示“待办”和“进行中”，完成与取消的任务可在设置中的“查看归档”恢复。
5. 右上角的图钉控制置顶；齿轮打开设置，可调透明度、管理分组、复制清单和批量导入。
6. 点右上角 `−` 收起为一个很小的半透明圆点；点圆点恢复。菜单栏的圆点图标也能打开窗口或退出应用。

### 自定义字体

在右上角的设置里，把 `.ttf`、`.otf` 或 `.ttc` 文件拖入虚线区域，也可以点“选择字体文件”。选中导入的字体后先看预览，再点“应用字体”；随时可以恢复系统字体。应用会把字体复制到本机数据目录，不会移动原文件，也不会将字体随源码上传。

应用只有本地数据，不需要账号，也不连接云端。清单保存在 `~/Library/Application Support/OrbTodo/tasks.json`。设置菜单中的“打开数据文件”可以在访达定位它。

## 与本机 AI 助手配合

可以让有本机文件访问权限的 AI 助手编辑 `tasks.json`。应用每秒检查一次文件，外部修改会自动显示。文件是 JSON，顶层包含 `categories` 字符串数组和 `tasks` 数组。每项任务包含：

```json
{
  "id": "唯一 UUID",
  "title": "任务内容",
  "category": "工作",
  "status": "todo",
  "createdAt": "2026-10-22T09:00:00Z",
  "dueAt": "2026-10-23T09:00:00Z"
}
```

`status` 可为 `todo`、`pending`、`completed` 或 `cancelled`。`dueAt` 可省略，表示没有截止时间。修改时保留已有任务的 `id` 和 `createdAt`，新增任务使用新的 UUID。写入完整有效的 JSON 后，窗口会自动刷新。旧版数字时间格式仍能读取；新版保存时使用 ISO 8601 字符串。

另一种方法是让 AI 输出多行待办文字，再在设置里选择“批量导入文本”。以 `# 分组名` 开头的行指定分组，其余每行添加一项。也支持 Markdown 的 `- [ ]` 和 `- [x]` 清单。

## 从源码构建

需要 Xcode 命令行工具。在源码目录运行 `./build.sh`。脚本会编译双架构应用、制作图标、进行本机签名，并将压缩包写入当前文件夹的 `dist` 子文件夹。

此版本使用本机签名，未经过 Apple 公证；首次在别的 Mac 上运行时，系统可能显示来源确认提示。
