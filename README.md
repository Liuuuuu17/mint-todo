# Mint Todo

一个 macOS 桌面悬浮待办应用。支持 Apple Silicon 和 Intel Mac，要求 macOS 13 或更新版本。

[下载 Mint Todo for Mac](dist/MintTodo-macOS.zip)

## 安装与使用

1. 解压 `MintTodo-macOS.zip`，将 **Mint Todo.app** 拖到“应用程序”文件夹，双击打开。
2. 在窗口底部选分组，输入待办，按回车或点 `+` 添加。
3. 点任务本身可以编辑内容、分组和截止时间。设置截止时间后，日期会显示在任务下方。
4. 点方框标记完成；点任务右侧的 `···` 可以改为“进行中”、完成、取消或删除。主界面仅显示“待办”和“进行中”，完成与取消的任务可在设置中的“查看归档”恢复。
5. 右上角的图钉控制置顶；齿轮打开设置，可调透明度、管理分组、复制清单和批量导入。
6. 点右上角 `−` 收起为一个很小的半透明圆点；点圆点恢复。菜单栏的圆点图标也能打开窗口或退出应用。
7. 拖动窗口右下角的斜箭头可以调整窗口大小，也可以在设置里用宽度和高度滑杆精确调整；新尺寸会保存在本机，下次打开仍然使用。

### 自定义字体

在右上角的设置里，把多个 `.ttf`、`.otf` 或 `.ttc` 文件拖入虚线区域，也可以点“选择多个字体文件”。导入的字体会成为可滚动选择的预设列表，每种字体都显示一行样例。选中字体后先看预览，再点“应用字体”；随时可以切换预设或恢复系统字体。应用会把字体复制到本机数据目录，不会移动原文件，也不会将字体随源码上传。

### 外观与背景

设置里可选择玻璃、实色、透明或照片背景。颜色选择器能改变实色底色或玻璃色调；“背景强度”控制背景本身的透明度，“整个窗口透明度”还会影响文字和按钮。照片模式支持从本机导入图片并调整缩放。macOS 26 及更新版本使用系统 Liquid Glass 效果；旧版 macOS 使用磨砂材质。背景照片保存在本机，不包含在安装包或 GitHub 仓库中。

### 苹果提醒事项

在设置中连接提醒事项，选择**一个**要同步的列表，再打开“双向同步”。应用会将该列表中的提醒导入本地，也会将本地待办写入该列表；新增、修改、完成与删除会同步到两边。同步约每 8 秒检查一次，也会在本地任务或提醒事项变化时尝试刷新。只有选定的列表会被读写；切换列表前可以先暂停同步。提醒事项权限由 macOS 管理。

**不需要开启 iCloud。** 选择列表时会显示“本机”或所属账户；如果系统提供本机存储，可点“创建本机 Mint Todo 列表”。授权后、从系统设置返回或列表变化时会自动刷新，也可点“刷新连接”。若旧列表标识失效，同步会暂停并保留本机数据，请重新选择当前列表再开启。仅显示可写列表；系统没有提供列表时会说明原因，不会要求强制开启 iCloud。截止时间会同步，通知由苹果提醒事项管理。

图标改为黑白灰的简约字标：纸白底、石墨色斜体 `m.`。

已放进“应用程序”文件夹的版本不会自动更新。下载新版后，先退出旧版，再把 **Mint Todo.app** 放入“应用程序”。原 **Orb Todo.app** 可移到废纸篓；不要同时运行两个版本。本机待办、字体和背景设置存放在应用外的数据目录，替换应用不会清除它们。

应用使用本地文件保存数据；启用提醒事项后，由苹果系统同步所选列表。清单保存在 `~/Library/Application Support/OrbTodo/tasks.json`。设置菜单中的“打开数据文件”可以在访达定位它。

## 与本机 AI 助手配合

可以让有本机文件访问权限的 AI 助手编辑 `tasks.json`。应用每秒检查一次文件，外部修改会自动显示。文件是 JSON，顶层包含 `categories` 字符串数组和 `tasks` 数组。每项任务包含：

```json
{
  "id": "唯一 UUID",
  "title": "任务内容",
  "category": "工作",
  "status": "todo",
  "createdAt": "2026-10-22T09:00:00Z",
  "dueAt": "2026-10-23T09:00:00Z"
}
```

`status` 可为 `todo`、`pending`、`completed` 或 `cancelled`。`dueAt` 可省略，表示没有截止时间。修改时保留已有任务的 `id` 和 `createdAt`，新增任务使用新的 UUID。写入完整有效的 JSON 后，窗口会自动刷新。旧版数字时间格式仍能读取；新版保存时使用 ISO 8601 字符串。

另一种方法是让 AI 输出多行待办文字，再在设置里选择“批量导入文本”。以 `# 分组名` 开头的行指定分组，其余每行添加一项。也支持 Markdown 的 `- [ ]` 和 `- [x]` 清单。

## 从源码构建

需要 Xcode 命令行工具。在源码目录运行 `zsh build.sh`。脚本会编译双架构应用、制作图标、进行本机签名，并将压缩包写入当前文件夹的 `dist` 子文件夹。

此版本使用本机签名，未经过 Apple 公证；首次在别的 Mac 上运行时，系统可能显示来源确认提示。

## 1.4 更新

应用更名为 Mint Todo，采用薄荷绿图标；修复切换应用后悬浮窗口隐藏的问题，并提高置顶层级。设置中的字体字号可在 10–24 pt 之间调整，实时生效。为保留旧版待办、字体和背景，数据目录与应用标识继续兼容旧版。更新前退出旧版，替换应用后只运行一个版本。

## 2.0 目标规划预览版（功能分支）

点击小窗口左上角或菜单栏的“我的目标”，打开独立的目标窗口。可以手动创建计划，或直接粘贴/选择 `orb-todo-plan-v1` JSON，再编辑预览并确认保存。无需配置 API Key。

每个目标包含阶段和正式任务，任务有可读、可编辑的 Markdown 执行说明。说明中的清单只记录操作细节，不会自动完成任务。目标任务只有在你主动选择“加入日常待办”后，才进入原待办及提醒事项同步。

可选 AI 设置支持自定义兼容 API 地址、模型和保存在 macOS 钥匙串的密钥。生成计划先预览；单任务 AI 细化可以追加、替换或取消。

目标保存在独立的 `goals.json`，原有待办、字体、背景和 Reminders 关联保留。更新前先退出旧版本；不要同时运行两个版本。目标文件提供上次保存备份与显式恢复入口。

开发架构、统计规则、数据兼容、构建方法和验证限制见 [DEVELOPMENT.md](DEVELOPMENT.md)。运行 `zsh test.sh` 执行隔离测试。V4 的整计划 AI 微调和自动重排期尚未启用。
